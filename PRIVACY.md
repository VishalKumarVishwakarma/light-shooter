# Privacy Policy — 8P Light Shooter (MVP)

**What we collect:** a self-chosen display name (callsign), gameplay stats for the current session (kills, deaths, wins — kept in server memory only), and basic connection logs (IP + timestamps, standard for any online game server).

**What we do NOT collect:** no accounts, no emails, no real names, no payment info, no tracking cookies, no third-party analytics or ad SDKs in the MVP build.

**Storage:** match state lives in server RAM and is discarded when rooms close. Your callsign and settings (name, mute, quality) are stored only in your own browser's localStorage — clear site data to erase them.

**Sharing:** we do not sell or share data. Connection logs exist for debugging and abuse prevention only.

**Children:** the game asks for nothing personally identifiable. Parents: the callsign is public to other players in the same lobby — pick something anonymous.
